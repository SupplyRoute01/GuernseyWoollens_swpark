# 건지울른스 브랜드 홈페이지

1976년 영국 건지 섬에서 시작된 건지울른스와 코튼 나그랑 크루넥 스웨터를 소개하는 한국어 정적 사이트입니다. 빌드 도구 없이 `index.html`이 저장소 최상위에 있습니다.

## 로컬 실행

```powershell
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. `index.html`을 직접 열어도 기본 기능은 동작합니다.

## 먼저 바꿀 내용

- 제품 가격, 재고와 상세 사이즈
- 상호, 사업자 정보와 주소
- 블로그 링크와 실제 게시일
- 문의 이메일과 인스타그램 주소

색상·레이아웃·접근성 원칙과 이미지 교체 방법은 `DESIGN.md`에 정리되어 있습니다.
