# 다정한 하루 브랜드 홈페이지

빌드 도구 없이 사용할 수 있는 한국어 정적 브랜드 사이트입니다.

## 실행

`index.html`을 브라우저에서 열거나, 로컬 서버를 실행하세요.

```powershell
python -m http.server 8000
```

그다음 `http://localhost:8000`에 접속합니다.

## 먼저 바꿀 내용

- 브랜드명: `다정한 하루`
- 이메일: `hello@example.com`
- 인스타그램: `@yourbrand`
- 대표자, 사업자등록번호, 주소
- 제품명, 가격, 원재료와 이야기 글

디자인 토큰과 수정 원칙은 `DESIGN.md`에 정리되어 있습니다.
